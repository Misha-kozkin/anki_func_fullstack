# Карты Anki — тренажёр словарного запаса

Репозиторий:

   ```bash
   https://github.com/Misha-kozkin/anki_func_fullstack.git
   ```

Консольное приложение для изучения иностранных слов

## Возможности

- загрузка словаря из файла `words.txt` при запуске;
- обычная тренировка: перевод случайных слов, пока не введено `СТОП`;
- тренировка до первой ошибки;
- добавление новых слов в словарь;
- просмотр всего словаря;
- сохранение словаря в файл при выходе;
- замер времени каждого ответа и итоговая статистика: счёт, общее и среднее время;
- проверка ответа без учёта регистра и пробелов по краям;
- обработка неправильного ввода в меню.

## Требования

- Python 3.12.

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/Misha-kozkin/anki_func_fullstack.git
   cd anki_func_fullstack
   ```

   2. Создайте и активируйте виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate        # macOS / Linux
   venv\Scripts\activate           # Windows
   ```

   3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   ## Запуск

```bash
python main.py
```

Пример работы:

```
Было загружено 9 слов из файла words.txt

Меню:
    1. Начать игру
    2. Добавить слова
    3. Тренировка до первой ошибки
    4. Вывод всех слов
    5. Выход

Пункт меню: 1
Чтобы закончить, введите СТОП
Ваше слово: кот
Ваш перевод: cat
Верно! Время на ответ: 1.24 секунд
Ваше слово: дом
Ваш перевод: стоп
Спасибо за игру!
Ваш итоговый счет: 1
Время игры: 1.24 секунд (среднее время: 1.24 сек.)
```

## Формат файла `words.txt`

Файл должен лежать в той же папке, что и `main.py`.
Одна пара на строку, слово и перевод разделены запятой без пробелов:

```
кот,cat
собака,dog
дом,house
```
